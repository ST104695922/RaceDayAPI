
# RaceDayAPI
RaceDayAPI is an ASP.NET Core Web API developed for the RaceDay event management system. The API supports user registration and login, profile management, event management, event categories, enrolments, payments and race results.

The project uses C#, ASP.NET Core Web API, SQL Server and Entity Framework Core. Swagger is used to explore and test the API endpoints during development.
Controllers/ — API endpoint controllers

Models/ — Database models and request models

Data/ — Entity Framework Core database context

Security/ — Authorization support, if stored in this folder

RaceDayAPI.Tests/ — Unit tests

Database/ — SQL database setup script
